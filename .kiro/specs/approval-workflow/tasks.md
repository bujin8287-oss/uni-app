## 注意事项

1. **参考实现**: 所有页面和功能的实现应该参考 uni-app 项目中的对应文件，确保功能和样式的一致性

2. **API 地址**: 当前 API 基础 URL 为 `http://localhost:3000`，需要根据实际后端服务地址进行配置

3. **用户信息**: 确保登录功能正确存储用户信息（userId, realName, user），审批流功能依赖这些信息

4. **样式单位**: 使用 rpx 作为响应式单位，确保在不同设备上的显示效果

5. **错误处理**: 所有 API 调用都需要处理成功和失败回调，提供友好的错误提示

6. **数据刷新**: 审批操作成功后需要刷新列表数据，确保数据的实时性

7. **登录逻辑**: 按照需求，登录页面的逻辑不需要修改，只需要确保审批流功能能够正确获取用户信息
